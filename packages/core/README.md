# @unison-ui/core

Platform-free building blocks for Unison components: props types, state hooks and style specs.

You normally don't install this directly; the renderers depend on it.

```bash
pnpm add @unison-ui/core
```

Exports today: `useControllableState`, `boxStyles`, `BoxProps`.

`@unison-ui/core` never imports `react-dom` or `react-native`, so it runs on every platform.

> **Preview.** Only `0.0.0-pr…` snapshot builds exist so far; the API will change before `0.1.0`.
> Part of [Unison](https://github.com/m-de-graaff/unison), a design system for React on the web
> and React Native, with motion built in. MIT licensed.
