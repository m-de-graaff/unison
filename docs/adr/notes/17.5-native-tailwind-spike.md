# Spike 17.5: native Tailwind engine (Uniwind)

Nov 19, 2026. Uniwind 1.14.0, Tailwind 4.3.5, Expo SDK 58 (React Native 0.88.1). Run in a Linux
cloud container, so there's no iOS Simulator or Android emulator. Bundle-level checks were done
with `expo export`; device checks are still open.

Decision: pending device tests (provisionally Uniwind)

## Setup

- `pnpm add uniwind tailwindcss` in `apps/mobile`.
- `metro.config.js` wraps the Expo config with `withUniwindConfig(config, { cssEntryFile: "./src/global.css", dtsFile: "./src/uniwind-types.d.ts" })`.
- `src/global.css` imports `tailwindcss`, `uniwind` and the token theme, and is imported in
  `src/app/_layout.tsx`. (SDK 58 puts routes in `src/app`, not `app`.)
- `SafeAreaView` from `react-native-safe-area-context` is wrapped with `withUniwind` to accept
  `className`.

## Test 1: `bg-accent` renders the accent colour

**First attempt, with `@unison-ui/tokens/theme.css`: fails (found in the bundle).** Uniwind keeps
the `var()` chain. `bg-accent` compiles to `vars["--color-accent"]`, which points at
`--unison-color-accent`, and nothing in the bundle defines that variable (`tokens.css` isn't
imported on native). On a device the square would render without colour, which is the failure
case the todo anticipated.

**The todo's fix: a third compiler output.** `dist/native/theme.css`, exported as
`@unison-ui/tokens/native-theme.css`, has literal values:
- an `@theme` block for `--radius-md` and `--spacing`
- `@layer theme { :root { @variant light {…} @variant dark {…} } }` for the colours

**Second attempt, with `native-theme.css`: passes at bundle level.** The Android bundle
(`expo export --no-bytecode`) contains:
- `scopedVars["__uniwind-theme-light"]["--color-accent"] = "#5b5bd6"`, with a matching dark
  scope
- `--spacing = 4`, so `size-24` = 96 = `size.box`
- `--radius-md = 8`

The iOS bundle also builds.

**Not yet verified:** the colour actually rendering on a device.

## Test 3: switching the system to dark updates `bg-surface` without a reload

**Partly verified (bundle level).** The dark scope holds `--color-surface: #111113`, and Uniwind's
default `system` theme follows the device colour scheme (Uniwind docs: Theming basics).

**Not yet verified on a device:**
- `xcrun simctl ui booted appearance dark` / `adb shell cmd uimode night yes`
- the in-app toggle, which calls `Appearance.setColorScheme`
